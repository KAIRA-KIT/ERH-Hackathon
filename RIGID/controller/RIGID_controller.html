Calibrate (saved on the robot)

  1. Only once, before tying lines: Centre, then tie each line on, snug by hand.
  2. Press Soft-tension. All six pull in together with the same small force, so the arm straightens itself. Tap or shake it gently so the joints settle.
  3. When the view shows it straight, press Save zero. Loads on every boot.
